# Automatic Classroom People Counter — Website

A lightweight, responsive project showcase built with plain HTML, CSS and JavaScript. No build tools or package installation required.

## Included
- Premium minimal gradient design with restrained 3D depth and motion
- Project overview, process pipeline, entry/exit logic, pin mapping and four team members
- Embedded 32-second project video **with its original audio**
- PDF project documentation link
- Mobile responsive layout and reduced-motion support

## Run locally
Open `index.html` in a modern browser. For best results, use a simple local server (for example, the VS Code Live Server extension).

## Publish with GitHub Pages
1. Create a repository on GitHub under `ObsedianGhost404` (for example, `classroom-people-counter`).
2. Upload the contents of this folder — `index.html`, `style.css`, `script.js`, and the `assets` folder. Do not upload only the ZIP.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site; the public URL will be shown in Settings → Pages.

## Audio behavior
The demo video includes an AAC audio track. It does not autoplay because modern browsers generally block autoplay with sound. Visitors can press play and adjust volume in the video player.

## Notes
- The occupancy figures in the hero illustration are decorative sample values, not a live sensor feed.
- The website describes the build using the provided project PDF: Arduino Uno, two IR sensors, and a 16×2 I²C LCD.
- The video file is kept in `assets/project-demo.mp4`; keep its filename and relative path unchanged.
